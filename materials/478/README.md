Run `python3 probe.py` from this directory. `storage.writer.PageWriter` and `query.reader.PageReader` are separately called production APIs. `storage.format` defines PCR2 framing; the reader fixture is assembled without invoking PageWriter. The starting code demonstrates ordinary lookup, a range crossing groups, and a variable-size edit that leaves downstream offsets stale. It is a runnable starting point, not the target implementation.
